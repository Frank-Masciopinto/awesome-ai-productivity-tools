Most productivity tools fail for the same reason: they need a new habit before they pay for
themselves. The ones here attach to something you already do. A meeting that was going to
happen anyway, an inbox you already open, a calendar someone else is filling in for you.

The categories follow a working week rather than a product taxonomy, which is why email and
calendars get as much room as note taking. Developer, marketing, and SEO tools are covered in
their own TiorAI repositories and are not repeated here, so nothing in this list is padding.

Maintained by [TiorAI](https://tiorai.com/), which catalogues AI tools for a living.

## Meetings and transcription

Notes, summaries, and actions from calls you were going to have anyway.

- **[Circleback](https://circleback.ai/)** — Meeting notes with action items that sync into task tools, and a strict privacy position on recordings. `Paid` `Web` `macOS` `iOS`
- **[Fathom](https://www.fathom.ai/)** — Records and summarises calls, with a free tier that most individuals never outgrow. `Freemium` `Web` `Windows` `macOS`
- **[Fireflies.ai](https://fireflies.ai/)** — Joins calls as a participant, transcribes them, and makes the archive searchable across a team. `Freemium` `Web` `iOS` `Android` · [vs Otter.ai](https://tiorai.com/compare/fireflies-ai-vs-otter-ai/)
- **[Granola](https://www.granola.ai/)** — Takes meeting notes from system audio without joining the call as a visible participant. `Freemium` `Windows` `macOS` `iOS`
- **[Krisp](https://krisp.ai/)** — Removes background noise from both sides of a call, and transcribes on top of it. `Freemium` `Windows` `macOS`
- **[Notta](https://www.notta.ai/)** — Transcription and translation across many languages, useful when the call is not in English. `Freemium` `Web` `iOS` `Android`
- **[Otter.ai](https://otter.ai/)** — Live transcription with a summary and action list, and one of the longer track records here. `Freemium` `Web` `iOS` `Android` · [free vs paid](https://tiorai.com/compare/otter-ai-free-vs-paid/)
- **[Read AI](https://www.read.ai/)** — Summarises meetings alongside engagement signals, aimed at teams reviewing how meetings go. `Freemium` `Web` `Browser Extension`
- **[Sembly](https://www.sembly.ai/)** — Meeting notes structured into decisions, risks, and follow-ups rather than one block of prose. `Freemium` `Web` `iOS` `Android`
- **[tl;dv](https://tldv.io/)** — Records calls with timestamped highlights you can clip and share without sending the whole recording. `Freemium` `Web` `Windows` `macOS` · [vs Otter.ai](https://tiorai.com/compare/otter-ai-vs-tldv/)

## Notes and knowledge management

Where the things you want to find again actually live.

- **[AFFiNE](https://affine.pro/)** — Documents and whiteboard on one canvas, local-first and self-hostable if you want the data close. `Open Source` `Web` `Windows` `macOS` `Linux`
- **[Anytype](https://anytype.io/)** — Local-first notes with end-to-end encryption and an object model rather than a folder tree. `Open Source` `Windows` `macOS` `Linux` `iOS` `Android`
- **[Capacities](https://capacities.io/)** — Organises notes by object type, so a person, a book, and a meeting behave differently. `Freemium` `Web` `Windows` `macOS` `iOS` `Android`
- **[Logseq](https://logseq.com/)** — Outliner storing everything as plain Markdown files you own, with backlinks between them. `Open Source` `Windows` `macOS` `Linux` `iOS` `Android`
- **[Mem](https://get.mem.ai/)** — Notes that organise themselves, surfacing related material instead of asking you to file it. `Freemium` `Web` `iOS` · [vs Notion](https://tiorai.com/compare/notion-ai-vs-mem-ai/)
- **[Notion](https://www.notion.com/)** — Documents, databases, and wikis in one workspace, with drafting and summarising built into pages. `Freemium` `Web` `Windows` `macOS` `iOS` `Android` · [vs Obsidian](https://tiorai.com/compare/notion-ai-vs-obsidian/)
- **[Obsidian](https://obsidian.md/)** — Markdown notes in a local folder, with a plugin ecosystem that covers most workflows you can name. `Freemium` `Windows` `macOS` `Linux` `iOS` `Android`
- **[Reflect](https://reflect.app/)** — Daily notes with backlinks and an assistant that drafts from what you already wrote. `Paid` `Web` `macOS` `iOS`
- **[Tana](https://tana.inc/)** — Structured notes with supertags, so a meeting note is also a queryable record. `Freemium` `Web` `Windows` `macOS` `iOS` `Android`

## How tools are selected

Three tests, and a tool has to pass all three.

**Does it remove a recurring chore?** Not an occasional one. Writing the meeting summary
every week counts; formatting an annual report does not.

**Does it attach to an existing habit?** The tool has to live where the work already happens:
in the calendar, in the inbox, in the notes app, on the call. Anything that needs a separate
tab you must remember to open loses most of its value in a real week.

**Does it save more time than it costs?** Setup, review, and correcting the output all count.
A summariser you have to check line by line has not saved anything.

What is deliberately elsewhere: developer tooling, marketing tools, and SEO tools each have
their own repository in this portfolio. A tool that genuinely serves two audiences appears in
both, with a description written for that audience rather than copied across.

What is excluded outright: products whose only productivity claim is an assistant panel, and
enterprise deployments that need an implementation project before anyone sees a benefit.

Entries are ordered alphabetically inside each category. Position carries no meaning, and
there is no paid placement, sponsorship, or affiliate link anywhere in this repository.
